## Model Routing and Cost Optimization

- Delegate mechanical repository inspection, OpenAPI parsing, endpoint inventories, schema extraction, and evidence collection to the cheapest capable agent.
- Use Opus for ambiguous requirements, architectural decisions, complex debugging, and final specification reviews.
- The analysis agent must distinguish verified facts from assumptions and missing evidence.
- Never invent API endpoints, response fields, status codes, or behavior.
- Produce structured evidence files that the specification author can consume without repeating the same repository exploration.
- Avoid duplicate analysis across agents. Escalate only unresolved questions or decisions requiring deeper reasoning.
