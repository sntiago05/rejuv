# ADR-0015: Product name "Rejuv"

- **Status**: Accepted
- **Date**: 2026-10-15

## Context
We need a brand that is short, works as a bot name, fits the game and does not use Valve's "Deadlock" trademark as the main name. Many community tools already use "lock" or "soul" (Statlocker, Tracklock, Buildlock, Soultracker...).

## Decision
**Rejuv**, from the Rejuvenator buff earned by killing the Mid Boss: to players it means "coming back stronger", which is the promise of coaching. Tagline: "Rejuv, an AI coach for Deadlock". Repo, package and bot use the same name (`rejuv`, `sntiago05.rejuv`).

## Consequences
- Check Discord app name, GitHub org/repo and a domain (e.g. rejuv.gg / getrejuv.com) before Phase 2 spending.
- "Deadlock" appears only in descriptions, never as the brand.
