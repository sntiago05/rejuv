## Status

## Summary
Task 047 updates the `/analyze` embed layout and redesigns the match chart generated by `ChartRenderer`:
1. **Embed Layout & Styling (`AnalyzeCommand`, `EmbedStyle`)**:
   - **Field order**: Reordered to **Biggest Leak** (keeps severity prefix), **Next Game Focus**, **Key Strength**, **Key Numbers**, **Final Build**, followed by chart attachment and footer.
   - **Emoji prefixes**: Added plain Unicode emojis via `messages.properties` keys (`⚠️` for leak, `🎯` for next action, `💪` for key strength, `📊` for key numbers, `🎒` for build).
   - **Monospace Key Numbers table**: Implemented `EmbedStyle.formatKeyNumbersTable(List<String>)` to format `<metric>: <yours> / <reference>` lines into an aligned monospace table (`metric | yours | reference`). Lines that do not match the pattern are preserved verbatim. The resulting code block is capped at 1,024 characters by dropping whole trailing lines.
   - **Discord limits defense**: Added defensive truncation caps for title (256 chars), description (4,096 chars), and footer (2,048 chars) using `truncate(text, max)` with trailing `"..."`.
2. **Domain & Service (`MatchVisuals`, `MatchVisualsService`)**:
   - Added `List<Integer> playerDeathTimesS` to `MatchVisuals.ChartData` (defensively copied, default constructor overload provided for backwards compatibility).
   - Updated `MatchVisualsService.buildChartData` to extract player death timestamps in seconds from `PlayerTelemetry.deaths()`.
3. **Chart Redesign (`ChartRenderer`)**:
   - Canvas height increased to 720 (900x720).
   - **Plain-language reading hints**: Added hints under both panel titles via new message keys (`analyze.chart.lead_hint` and `analyze.chart.networth_hint`).
   - **Phase bands**: Rendered subtle background bands and centered labels for Laning (< 12 min / 720s), Mid Game (< 20 min / 1200s), and Late Game.
   - **Death markers**: Placed `0xED4245` circular markers with dark outline on the player net worth curve at each death timestamp (interpolating y coordinates along the player series), with a legend entry ("Your deaths"). Skips rendering when the list is empty or times are outside the series.
   - **Direct series labels**: Removed the old net worth legend in favor of direct end-of-line labels ("You" in gold `0xFFC83D`, "Teammates avg" in grey `0x9AA0A6`) placed in the right margin with vertical collision avoidance.
   - **Direct side labels & final lead annotation**: Labeled lead panel sides ("Your team ahead" in blue `0x4C9BE8`, "Enemy ahead" in orange `0xF28C28`) at zero-line edge, and added signed final lead annotation (e.g. `+3.4k at 28 min`) next to the last point.
   - Failure behavior preserved: returns `Optional.empty()` on invalid series or rendering exceptions.
4. **Localization (`messages.properties`)**:
   - Added emoji prefixes to existing field keys.
   - Added new keys: `analyze.chart.lead_hint`, `analyze.chart.networth_hint`, `analyze.chart.phase.laning`, `analyze.chart.phase.mid`, `analyze.chart.phase.late`, `analyze.chart.deaths_label`, `analyze.chart.side_you`, `analyze.chart.side_enemy`, `analyze.chart.final_lead`.

## Decisions
- **Key Numbers Table Parsing**: Splits each line on the first `": "` and the last `" / "` to extract `metric`, `yours`, and `reference`. If a line does not match this structure, it is kept verbatim without formatting. Columns are padded to the maximum widths of parsed metrics and user values. The table is wrapped in a Markdown code block (` ```\n...\n``` `) and capped at 1,024 characters using `EmbedStyle.fitLines` (dropping whole trailing lines from the end).
- **Death Marker Interpolation**: For death timestamps between telemetry sample points, linear interpolation is computed along the player net worth curve to position death markers at their exact (x, y) coordinates.
- **Direct Label Placement**: The canvas right margin (`RIGHT = 110`) provides sufficient horizontal space to display end-of-series labels ("You", "Teammates avg") and the final lead value outside the plot frame without obstructing data curves. A vertical offset shift (+/- 7px) prevents collision if the two net worth lines terminate at nearby y values.
- **CPU Benchmark SHA-256**: The new 900x720 chart canvas with phase bands and direct annotations changes the rendered PNG output. As noted in the spec, `CpuHotPathBenchmarkTest` was executed to measure the updated performance and hash rather than modifying the benchmark logic.
